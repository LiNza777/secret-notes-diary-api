# Secret Notes API

REST API для хранения личных заметок с JWT-аутентификацией, ротацией refresh-токенов в Redis и обработкой фоновых задач.

Каждый пользователь имеет собственное изолированное пространство заметок. Поддерживаются регистрация, авторизация, обработка асинхронных задач, CRUD-операции над заметками, миграции базы данных и контейнеризация через Docker.

## Возможности и Безопасность

- **Двухуровневая аутентификация (JWT):** Короткоживущие Access-токены и долгоживущие Refresh-токены через безопасные `HttpOnly` Cookie.
- **Управление сессиями в Redis:** Хранение Refresh-токенов с автоматическим истечением срока (TTL) и ротацией при обновлении.
- **Мгновенный отзыв сессий (Logout):** Удаление токена из Redis полностью блокирует возможность рефреша сессии.
- **Фоновые задачи (Background Tasks):** Асинхронная обработка тяжелых процессов при регистрации пользователя (например, отправка приветственных писем/уведомлений) без блокировки HTTP-ответа.
- **Безопасность:** Хэширование паролей с помощью `bcrypt`, защита от XSS (`HttpOnly`) и CSRF (`SameSite=Lax`).
- **Изоляция данных:** Каждый пользователь имеет доступ строго к своим заметкам.
- **ORM и Миграции:** SQLAlchemy ORM и автоматическое управление схемой через Alembic.
- **Контейнеризация и CI/CD:** Полная сборка через Docker Compose и автопрогон тестов в GitHub Actions.


## Технологии
- **FastAPI** — асинхронный веб-фреймворк для создания API.
- **PostgreSQL & SQLAlchemy** — реляционная база данных и ORM.
- **Redis** — in-memory хранилище для управление сессиями и refresh-токенами.
- **FastAPI BackgroundTasks** — асинхронные фоновые задачи.
- **Alembic** — управление миграциями базы данных.
- **Docker & Docker Compose** — контейнеризация приложения и сервисов.
- **PyTest & Fakeredis** — интеграционное тестирование с эмуляцией Redis в памяти.
- **GitHub Actions** — CI/CD пайплайн для автоматического прогона тестов.

## Запуск проекта

1. Клонируйте репозиторий:
   ```bash
   git clone <url_репозитория>
   cd secret-notes-api
   ```
2. Создайте файл `.env` на основе шаблона и заполните его своими данными:
   ```bash
   cp .env.example .env
   ```
3. Запустите проект в Docker:
   ```bash
   docker compose up --build
   ```
4. Примените миграции для создания таблиц в базе данных:
    ```bash
    docker compose exec app alembic upgrade head
    ```
5. Интерактивная документация API (Swagger) будет доступна по адресу: `http://localhost:8000/docs`

## База данных
Связь таблиц «Один ко многим» (One-to-Many):
- `users` (id, username, hashed_password)
- `notes` (id, title, content, created_at, updated_at, owner_id → users.id)


## Эндпоинты

### Auth
- `POST /auth/register` — регистрация
- `POST /auth/login` — вход, возвращает JWT в куки
- `POST /auth/logout` — выход

### Notes
- `GET /notes/` — все заметки текущего пользователя
- `POST /notes/` — создать заметку
- `GET /notes/{id}` — получить заметку
- `PATCH /notes/{id}` — обновить заметку
- `DELETE /notes/{id}` — удалить заметку

## Тестирование

В проекте написаны интеграционные тесты с использованием `pytest` и `TestClient` (FastAPI). Тесты покрывают жизненный цикл аутентификации: регистрацию, логин, проверку защищенных эндпоинтов и логаут.
- CI/CD: Настроен автоматический прогон тестов через GitHub Actions при каждом `push` и `pull request`.
- Тестовое окружение: Для изоляции тестов используется `fakeredis` (эмуляция в оперативной памяти), поэтому запускать отдельный сервис Redis для прогона тестов не требуется.
